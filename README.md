# Landing page de vendas

Página React de divulgação e captura demonstrativa de nome e e-mail.

## Recursos

Formulário com validação de preenchimento e retorno visual para o visitante.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/landingpage-vendas.git
cd landingpage-vendas
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.
